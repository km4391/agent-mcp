Act I · The Setup

Give a local agent a shell. Keep your Mac.

LM Studio, Claude Desktop, Cursor, Cline, Goose: anything that speaks MCP gets a terminal and file tools. The dangerous parts are fenced off by the operating system, not by hoping the model behaves.

Act II · The Entrance

Install

The installer builds a venv, installs the MCP SDK, runs the doctor to prove the sandbox is enforcing on your Mac, then writes mcp-config.json for your client. Needs Python 3.10+.

git clone https://github.com/km4391/agent-mcp ~/agent-mcp
cd ~/agent-mcp && ./install.sh

Then paste into your client's MCP config, restart it, and ask the model to call agent_info:

{ "mcpServers": { "agent-mcp": {
    "command": "/Users/YOU/.agent-mcp/bin/python",
    "args": ["/Users/YOU/agent-mcp/agent_mcp_server.py"],
    "env": { "AGENT_WORKSPACE": "/Users/YOU/AgentWorkspace" } } } }
Act III · The Repertoire

Twenty tools, one stage

Terminal

run_command. On timeout it keeps running in the background.

Long-running

start_process, read_output with a wait_for regex, send_input, kill_process, list_processes.

Code

run_code for Python, Node or shell snippets.

Files

Paged read_file, write_file, list_directory trees, move_path, get_file_info.

Edit

edit_block: exact search/replace, occurrence check, closest-match hint, unified diff back.

Search

search_files by name, search_code by regex, using ripgrep when present.

Delete

delete_path moves to .trash/. Nothing is destroyed.

Web

fetch_url, allowlisted hosts only.

Not on the bill: set_config. The policy is fixed at launch by environment variables. No tool can loosen it from inside.

Act V · The Confession

What it does not cover

  • GitHub is on the default allowlist, and git push can exfiltrate. Keep secrets out of the workspace, or drop it with AGENT_NET_ALLOW_ONLY.
  • Localhost is reachable by default so the agent can reach Ollama. A local proxy or VPN client would bypass the allowlist. Set AGENT_ALLOW_LOCALHOST=0 if you don't need it.
  • The workspace is fully exposed. Treat it like a shared folder with a very fast, occasionally confused intern.
  • File tools run in the server process, confined by path validation (symlinks resolved, tested), not by the kernel.
  • Resource exhaustion is bounded, not prevented.
  • sandbox-exec is deprecated by Apple. It still works through macOS 26. The server refuses to start without it rather than run unsandboxed.
  • Prompt injection is still the main risk. The sandbox limits the blast radius. Keep your client's per-call approval on.
Hardened against the common ways a local agent harms a machine: the home-folder wipe, the credential theft, the "curl everything to pastebin", the AppleScript takeover. It is not a VM.
Act VI · The Alibi

The doctor

About 16 checks, run through the real sandbox. Re-run after any macOS update.

~/.agent-mcp/bin/python agent_mcp_server.py doctor
  • profile compiles
  • shell, python, node work
  • workspace writes succeed
  • outside writes fail
  • ~/Library unreadable
  • ~/.ssh unreadable
  • osascript / open can't run
  • direct network refused
  • pypi.org works via proxy
  • example.com returns 403
  • pip install into a venv works
  • "All required checks passed"
